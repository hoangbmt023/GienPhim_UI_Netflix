
## Project Purpose
This project was developed as a technical practice product, focusing on:
- Building a **cinematic** and smooth user interface.
- Optimizing the movie-watching experience on **all devices**.
- Testing the latest modern web technologies.

## Copyright Disclaimer
GienPhim **does not directly store** any video files on its servers.
- All movie content and links are automatically collected from **free sharing sources** on the Internet via APIs.
- We are not responsible for the content of these files. If you are a copyright owner, please contact the original video server provider to request removal.

## User Experience
We are committed to not placing annoying ads, not requiring paid subscriptions, and always trying to maintain the most stable system possible to serve the movie-loving community.
